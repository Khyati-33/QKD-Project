# Final manuscript comparison figures

This directory is reserved for the matched GNN-PPO versus LSTM-PPO results used in `paper/main.tex`. The four primary plots are generated from `experiments/final_gnn_lstm_holdout_20261007.json` by `python scripts/plot_gnn_lstm_comparison.py`; each is exported as vector PDF and high-resolution PNG. They cover overall completion and successful-route hops, season/time completion, matched checkpoint variability, and CPU p95 inference latency. The reward-component plot is generated by the paired audit and is included only after that audit completes.

Older comparisons against other architectures or route-selection methods are kept under `paper/figures/archived_baseline_comparisons/` and are not used as the main paper's architecture comparison.
